# 🌸 Megg Through The Years (`stunning-enigma`)

> *"A living gallery celebrating your beauty, your laughter, and the unforgettable eras that brought us here."*

An intimate, motion-rich, and interactive website designed as a celebration of **Megg** through the years. Styled with the award-winning **Jayesh Patil Light Theme** aesthetic (warm sunset orange `#FF7843`, crisp typography in Plus Jakarta Sans, frosted glassmorphism, and responsive bento grid).

---

## 🚀 How to View & Run Locally

### Option 1: Direct Double-Click (Zero Setup)
Simply double-click `index.html` in Windows File Explorer. It opens instantly in Google Chrome, Microsoft Edge, or Safari without requiring any local server or install steps.

### Option 2: Local Node.js Server
Double-click `start.bat` (or run in terminal):
```powershell
node serve.js
```
Then navigate to `http://localhost:3000`.

## 🌐 Free One-Click Hosting with GitHub Pages

You can publish this website live on the web for free using GitHub Pages:

1. Open your repository on GitHub: [https://github.com/Juju18-ux/stunning-enigma](https://github.com/Juju18-ux/stunning-enigma)

3. Under **Branch**, select `main` and folder `/(root)`, then click **Save**.
